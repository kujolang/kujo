## Gotchas (Read This Next Time)

- A release publish job that has not checked out the repository must pass `--repo` explicitly to `gh workflow run`.
- Windows artifact smoke extraction must resolve the downloaded archive to an absolute path before changing directories.

## Things I Learned

- The release-assets publish operation and every artifact build succeeded even though the original workflow run concluded failure in its final smoke-dispatch step; the independently dispatched artifact smoke run is the authoritative post-publish verification.
