# Kujo repository guide agent

This checked-in project is generated by Kujo itself. It demonstrates a
repository-owned knowledge agent that can explain the Agent Project contract
using local, cited knowledge. The agent definition, instructions, provider
preference, skills, policies, retrieval configuration, evaluation, and runtime
boundary remain ordinary reviewable files.

```bash
kennel install
kujo doctor agent
kujo agent inspect
kujo agent run "How does this repository own its agent?"
kujo agent eval
```

Fixture mode uses the Agents SDK no-network harness and local RAG adapter, so it
requires no provider credentials. Change `config/model.json` for a live AI SDK
provider and provide credentials through the environment only. Kujo
capabilities authorize effects; they are not a sandbox. Use a hardened project
and Workcell for a container-backed isolation boundary.
