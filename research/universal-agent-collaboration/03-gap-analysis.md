# 03. Evidence-backed gap analysis

Classification applies to the **universal Software Factory use case**. A partial equivalent can be complete at its original narrower boundary. [01](01-repository-inventory.md) pins source identities, [02](02-existing-capabilities.md) defines fresh and retained evidence, and [09](09-evidence-ledger.json) records each finding. Absence is scoped to inspected tracked implementation, packages, schemas, tests and adjacent integrations.

| ID | Component | Classification | Evidence and disposition |
|---|---|---|---|
| UC-01 | Agent identity registry | **PARTIAL** | `kujo-agents/agent-registry.json` and canonical manifests, Factory `roleContract`, City `importCatalog`; Factory `role-runtime.test.mjs` and City `profile-binding.test.ts` passed. Reuse catalog IDs and pinned role definitions. Add workspace principal and external account mappings. Keep definition, deployment, actor and run identities distinct. |
| UC-02 | Messaging core | **PARTIAL** | SDK `sessions/store.kujo#create_session_message_impl` and session-store tests cover model context. City `apps/gateway/journal.ts` and `real-replay.test.ts` cover observation replay. Board and upstream Paperclip provide external conversations. Add only admitted mission thread/messages, referenced replies and visibility, or qualify Board's local backend behind the same ports. Avoid a general chat product. |
| UC-03 | Event bus | **PARTIAL** | Dispatch `hooks.kujo#emit_hook_event/replay_webhook_outbox` and the concurrent sink test establish lifecycle export, durable outbound behavior in source, and local serialization. Leash has intervention-specific receipts. Reuse source projections. Add inbound occurrence deduplication and destination delivery at the collaboration boundary. A distributed broker is **UNNECESSARY** for the pilot. |
| UC-04 | Task coordination | **REUSABLE** | Factory `applicationTeam`, `worker.mjs#handoff` and Dispatch `run_workflow_unlocked` provide assignments, dependencies and scoped handoffs for the first fixed team. `role-runtime.test.mjs` and production recovery receipt. Cross-run requests for help/review need an intent record; no second execution scheduler is warranted. Board claims and Paperclip checkout may own outside backlog only. |
| UC-05 | Dispatch bridge | **REUSABLE** | `factory/dispatch.kujo#factory_worker`, `executeRun`, and `createControlSession` already submit fixed local mission workflows. `control-mcp.test.mjs` passed. Extend only the local correlation/admission seam after verifying identity and presenting an operator-reviewed intent. External adapters must have no native resume, tool or release privilege. |
| UC-06 | Permission engine | **PARTIAL** | Factory control grants and operations policy, Dispatch `validate_intervention_decision`, Workcell `src/policy/policy.kujo` and Ability Gateway `src/auth.ts`. Factory control/operations suites and Dispatch revision suite. Reuse those controls and add workspace membership, object/channel bindings, identity proof and request quota before native admission. Avoid centralizing native controller authority in a new policy engine. |
| UC-07 | Slack adapter | **PARTIAL** | Leash inbound provider routes and `verify_slack_signature`/normalization with `slack_thread_reply_is_bounded_and_normalized` and stale signature cases. Upstream Paperclip and Chat SDK add useful transport. No verified end-to-end Factory contract. Add adapter over the shared envelope; keep Slack-specific effects inside it. |
| UC-08 | Teams adapter | **PARTIAL** | Upstream Paperclip fork `chat-channels.ts#chatWebhookRoutes`, `microsoft-teams/messages.ts`, `doc/plans/chat-adapters/2026-09-05-teams-live-qualification-result.md`; vendor SDK also exists. Kujo plugin tests only scope host control. Reuse transport implementation/patterns under new Factory bindings. No first-party Kujo-native Teams path was verified. |
| UC-09 | Board adapter | **MISSING** | No Board SDK/CLI bindings found in audited Factory, Dispatch, SDK or plugin control code or their tests. Board's own `backend-local`, `server/tasks.ts#createTasks`, `sync/engine.ts#createSyncEngine`, `tasks.test.ts` and `sync.test.ts` verify implementation presence in external source, not integration. Add optional adapter, qualify backend separately. |
| UC-10 | Paperclip adapter | **PARTIAL** | Kujo plugin `src/features/dispatch/control.ts`, `decision-observation.ts` and host workspace tests passed. Upstream `issueRoutes`, wakeup and native chat have separate contracts. Build a constrained intent/receipt bridge in the plugin over the upstream task API or plugin host; existing plugin control stays scoped. |
| UC-11 | Custom API/SDK | **PARTIAL** | Factory `createControlSession` and MCP tool schemas, Agents SDK typed handoffs, Ability Gateway `src/api.ts` and `test/approval-binding.test.ts` offer reusable patterns. Add a small workspace-scoped versioned adapter contract and conformance fixtures. Defer a generally distributed SDK until a second consumer. |
| UC-12 | Factory Floor integration | **PARTIAL** | `factory/mission-observer.mjs#createMissionObserver`, `operator-model.mjs`, GET routes and `mission-observer.test.mjs` cover evidence and recorded control. Add read-only redacted collaboration projections keyed by existing mission/run IDs. Retain default read-only authority. |
| UC-13 | Cross-platform links, echo control and recovery | **MISSING** in the Factory path | No durable multi-connector origin/copy mapping or canonical peer intake found in Factory controller/MCP or Dispatch hooks. Board has a sync engine and test fixtures, Leash has decision retry. Require occurrence and command dedupe independently; one connector owns each mirror path. |
| UC-14 | Between-run and cross-factory peer routing | **PARTIAL** | Agent definitions survive runs, Product Launch pins and runs child factories, SDK registry routes in-process, and Factory exposes evidence. Those paths do not verify dormant-agent wake via authorized address or general cross-factory delegation. Model it as a bounded, policy-checked request addressed to a registered deployment. |
| UC-15 | Hosted Board parity and production local embedding | **UNKNOWN** | Board's source and conformance tests establish documented local capabilities. Multi-user auth parity, deployment hardening, support, recovery at scale, compatibility and team/tenant behavior need independent qualification. |
| UC-16 | Separate execution/approval ledger | **UNNECESSARY** | Dispatch state and revision tests, Workcell evidence, Factory `promoteAccountedRelease` and Paperclip plugin observation tests already provide bounded authority. Store links/digests and grant audit with distinct scope. |
| UC-17 | Read-only run evidence for collaboration UI | **EXISTS** | The bounded scope required for initial projection is implemented by `createMissionObserver` and controller-owned evidence routes. Fresh `mission-observer.test.mjs` and retained Floor receipt. Shared conversation rendering remains UC-12. |
